Sprite Studio ’98 Help

The complete artwork workflow

  1. Choose Map Sprites 48×48 or Heroes 96×96. Events and UI Icons are reserved for future activation.
  2. Press Open Sheet or paste an image with Ctrl+V.
  3. Use Drag select around one source icon. Use Move square or arrow keys for exact placement.
  4. Release the mouse or press Preview crop in Paint. Oversized artwork is reduced proportionally; smaller artwork is never enlarged. It is bottom-centred on the transparent checkerboard.
  5. Retouch in Paint. The checkerboard is transparency and is never exported.
  6. Click the intended atlas cell. Its preset name, stable ID, artwork and assignment details load automatically.
  7. Press Save Artwork to Address. Existing artwork requires confirmation. Assignment details are not changed when artwork is replaced.
  8. Add map matches only when needed. The first 83 sprite names and 146 hero names are already prepared.
  9. Use Save Project Backup regularly. It contains both operational atlases and the reserved future namespaces.
  10. Press Export for ArcheoMaps to download both atlas PNGs and the combined runtime manifest.

Permanent-address rule: after an address is released, redraw its artwork freely but never move its stable ID to another cell.
